# Coding-Stil

Code soll selbstbeschreibend sein: aussagekräftige Funktions- und Variablennamen statt Kommentare. Keine Kommentare hinzufügen, außer ein nicht offensichtliches WARUM muss festgehalten werden (versteckte Einschränkung, Workaround, überraschendes Verhalten) – nie WAS der Code tut, das sollen die Namen schon zeigen.
